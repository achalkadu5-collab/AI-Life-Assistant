# AI Life Memory & Decision Assistant
## Project Overview
An AI-powered personal assistant that remembers user information,tracks goals, analyzes documents,manages schedules,and helps users make better decisions.

## Objectives
To build an intelligent assistant using python that stores user memory and provides personalized suggestions.

## Features
-User login
-AI chat
-Memory system
-Goal Tracker
-Document Reader
-OCR
-Voice Assistant
-Expense Tracker
-Calender
-Analytics Dashboard

## Technologies
-Python
-FastAPI
-Streamlit
-SQLite
-ChromaDB
-LangChain
